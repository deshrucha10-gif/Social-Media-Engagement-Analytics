# Social Media Engagement Analytics Dashboard

## Project Overview
This project uses Tableau to analyze social media engagement and present insights through an interactive dashboard.

## Objectives
- Analyze engagement across social media platforms.
- Compare engagement by content type.
- Examine monthly engagement trends and posting times.
- Identify the top 10 posts by engagement.
- Explore sentiment and summarize key metrics using KPI cards.

## Tools and Technologies
- Tableau
- Microsoft Excel
- GitHub

## Dashboard Features
- Total Engagement KPI
- Total Likes KPI
- Total Posts KPI
- Average Engagement per Post KPI
- Platform Engagement
- Content Type Engagement
- Monthly Engagement Trend
- Engagement by Posting Time
- Top 10 Posts by Engagement
- Sentiment Analysis

## Project Files
- `Social_Media_Engagement_Analytics_Report.pdf` — Project report
- `Social_Media_Engagement_Analytics_Report.docx` — Editable report
- Tableau workbook — Dashboard and visualizations
- Dataset or source link — Data used in the project
- Dashboard screenshot — Final dashboard preview

## How to Use
1. Download the Tableau workbook.
2. If necessary, reconnect it to the source dataset.
3. Open the workbook in Tableau.
4. Use the dashboard filters to explore engagement patterns.
